为了更好的拟合非线性，因此出现非线性激活，也就是激活函数
下面是激活函数的演变
第一阶段
首先就是sigmoid函数
σ(x)=1+e−x1​
输出范围是0,1，曲线平滑，能够把实数映射到对应的概率值，缺点在于，在横轴小或者大的情况下会出现梯度为0的情况，导致梯度消失，深层网络传播的过程中梯度会逐渐变小
其次是tanh函数
tanh(x)=ex+e−xex−e−x​
输出范围为 (−1,1)，中心点是零。相比 Sigmoid，它允许负数输出，因此隐藏层的激活值更容易以零为中心，相比于sigmoid改进了使0为中心，但任然没解决在两端出现梯度接近于0的问题
第二阶段
RELU家族
f(x)=max(0,x)
在正半轴，导数恒为 1，不会像 Sigmoid 一样随着正输入增大而逐渐趋近于零。因此，它使深层网络更容易训练，而且计算成本低。但是如果一直是负输入，那么它一直就为零，导致梯度也为零，无法更新，没法通过梯度更新得到好的改进
Leaky ReLU
f(x)=max(αx,x)
系数α是一个很小的值，解决了输入值为负的时候神经元失活的问题，但是局限在于系数是一个参数，需要调参才能得到一个比较好的
PReLU
f(x)=max(αx,x)
它和 Leaky ReLU 的公式一样，但有一个关键区别：负半轴的斜率 α 可以通过训练学习
ELU
正半轴仍然是线性的；负半轴则通过指数函数平滑地趋向 −α。
SELU
SELU 在 ELU 的基础上增加缩放系数，目标是在特定网络条件下，使层与层之间的激活均值和方差趋于稳定。
ReLU 很高效，但在 x=0 处存在拐点，负半轴又直接截断。于是，研究者开始探索更平滑的函数，让输入的贡献能够连续变化。
第三阶段
Softplus
f(x)=ln(1+ex)
可以把它理解为 ReLU 的平滑版本。
当输入很大时，Softplus 近似 x；当输入很小时，输出接近零，但不会像 ReLU 一样突然截断。
GELU
GELU(x)=xΦ(x)
GELU 用高斯累计概率 \(\Phi(x)\) 作为一个软门控系数，根据输入大小决定保留多少信息。大的正输入对应累计概率接近1，所以基本保留；大的负输入对应累计概率接近0，所以被抑制。
Swish / SiLU
SiLU(x)=xσ(x)
Swish(x)=xσ(βx)
用 Sigmoid 根据输入大小控制输入自身的通过程度。
与 ReLU 相比，它的曲线平滑，负半轴允许小幅负输出；在部分视觉模型和现代网络中表现良好。
Mish
f(x)=xtanh(ln(1+ex))
同样类似于前面的设计
第四阶段
GLU
GLU(a,b)=a⊙σ(b)
a 和 b 是同一个输入 x 经过两个不同的线性层得到的两个对应位置的特征向量。a 提供内容，b 经过 sigmoid/SiLU 后生成门控权重，然后逐位置相乘，让网络学习每个隐藏特征应该保留多少。
SwiGLU
SwiGLU(x)=SiLU(xW)⊙(xV)
对于这两种有什么不同，GLU中的门控只能将范围压缩到0,1之间，对于特征来说相当于是一种概率分布的门控，SwiGLU中改成了更平滑的函数，不再将其压缩至0，1直接而是会更大，不再表示概率
增加了非线性变换
